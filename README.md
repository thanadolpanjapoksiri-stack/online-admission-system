# ระบบรับสมัครเรียนออนไลน์ครบวงจร (Online Admission System)

ระบบบริหารจัดการการรับสมัครนักเรียน-นักศึกษาใหม่ (ระดับ ปวช. และ ปวส.) รองรับการทำงานทั้งฝั่งผู้สมัคร (Front-end) และฝั่งเจ้าหน้าที่งานทะเบียน (Back-end)

---

## 🚀 ฟังก์ชันการทำงานหลัก

### 1. ฝั่งผู้สมัครเรียน (Applicant Portal)
1. **ระบบกรอกใบสมัคร & Data Validation:**
   - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลักด้วยอัลกอริทึม Checksum (Mod 11) ของไทยแบบเรียลไทม์
   - ตรวจสอบรูปแบบเบอร์โทรศัพท์มือถือ 10 หลัก (ขึ้นต้นด้วย 0)
   - ปฏิทินเลือกวันเดือนปีเกิด
   - Dropdown เลือกระดับชั้น (ปวช. / ปวส.) และสาขาวิชาจะเปลี่ยนตามระดับชั้นที่เลือกโดยอัตโนมัติ
   - ข้อมูลประวัติการศึกษาเดิม, เกรดเฉลี่ย (GPAX), ผู้ปกครอง และช่องทางประชาสัมพันธ์
2. **ระบบอัปโหลดเอกสารหลักฐาน:**
   - รองรับ 4 รายการหลัก: รูปถ่ายหน้าตรง, สำเนาบัตรประชาชน, สำเนาทะเบียนบ้าน, ใบแสดงผลการเรียน (รบ./ปพ.1)
   - จำกัดประเภทไฟล์ `JPG`, `PNG`, `PDF` ขนาดไม่เกิน `5MB`
3. **ระบบตรวจสอบสถานะการสมัคร:**
   - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก
   - แสดง Progress Tracker 4 ขั้นตอน: ยื่นใบสมัคร -> ตรวจสอบเอกสาร -> ผ่านการคัดเลือก -> มอบตัวสำเร็จ
   - หากเอกสารไม่สมบูรณ์ มีช่องให้อัปโหลดเอกสารแก้ไขเพิ่มเติมได้ทันที
4. **ระบบพิมพ์/ดาวน์โหลดเอกสาร (PDF):**
   - พิมพ์ใบสมัครราชการขนาดมาตรฐาน A4 (มีกรอบรูปถ่าย, ตารางข้อมูล, ช่องลงชื่อผู้สมัคร/ผู้ปกครอง/เจ้าหน้าที่)
   - พิมพ์ใบมอบตัวและสัญญามอบตัวเป็นนักศึกษา

---

### 2. ฝั่งเจ้าหน้าที่และผู้ดูแลระบบ (Admin / Back-end Portal)
1. **เข้าสู่ระบบสำหรับเจ้าหน้าที่:**
   - บัญชีเริ่มต้น: `admin` / รหัสผ่าน: `admin1234`
2. **แดชบอร์ดสรุปสถิติแบบเรียลไทม์ (Dashboard & Analytics):**
   - KPI สรุปยอดผู้สมัครทั้งหมด, รอตรวจสอบ, ผ่านการคัดเลือก, มอบตัวแล้ว, เอกสารไม่ครบ
   - กราฟโดนัท (Doughnut Chart) แสดงสัดส่วนตามระดับชั้น (ปวช. vs ปวส.)
   - กราฟแท่ง (Bar Chart) แสดงจำนวนผู้สมัครแยกตามสาขาวิชา
   - อันดับโรงเรียนเดิม และช่องทางการประชาสัมพันธ์
3. **ระบบจัดการและตรวจสอบข้อมูลผู้สมัคร:**
   - ค้นหาและกรองข้อมูลตามระดับชั้น, สาขาวิชา, และสถานะ
   - ปุ่มเปิดดูไฟล์แนบเอกสาร (เปิดภาพหรือไฟล์ PDF ได้ในเบราว์เซอร์ทันที)
   - ปรับเปลี่ยนสถานะพร้อมระบุหมายเหตุถึงผู้สมัคร
4. **ระบบออกรหัสประจำตัวและจัดการการมอบตัว:**
   - Auto-generate Student ID ตามปีการศึกษาและรหัสสาขาวิชา (เช่น `68201010001`)
   - บันทึกชื่อพยาน วันที่มอบตัว
5. **ระบบส่งออกข้อมูล (Export Data):**
   - ส่งออกเป็นไฟล์ **Excel (.xlsx)** และ **CSV** จัดรูปแบบตามมาตรฐานงานทะเบียน ศธ.02 นำเข้าสู่ระบบทะเบียนวิทยาลัยได้ทันที
6. **ระบบแจ้งเตือนอัตโนมัติ (LINE Notify / System Log):**
   - รองรับการใส่ Token LINE Notify
   - แจ้งเตือนเมื่อมีผู้สมัครรายใหม่ และเมื่อมีการอัปเดตสถานะ
